03 / MAKE YOURSELF AT HOME

你的第一场放映，
从这里开始。

准备好收藏。
剩下的，交给 Mochi 慢慢整理。

  1. 01

    配置元数据

    在「设置 → 元数据」填写自己的 TMDB API Key；按需配置 HTTP 代理。

  2. 02

    连接媒体源

    在「设置 → 媒体源」添加本地目录、WebDAV 或 SMB，并检查连接。

  3. 03

    扫描，然后开场

    扫描媒体源，整理影片信息。从媒体库挑选一部，开始观看。

A FEW MORE THINGS

你可能还想知道

Mochi 会提供影片资源吗？

Mochi 用于整理和播放你已有的媒体文件。请自行准备有权使用的影片，并配置媒体源。

我的媒体库数据存在哪里？

媒体库、进度与设置保存在本机。启用 TMDB 后，匹配所需的影片名称等信息会发往配置的 TMDB 服务。当前媒体源凭据保存在本机数据库，尚未接入系统钥匙串。

支持 Emby 或系统画中画吗？

Emby 接入仍是后续计划。当前的小窗是可置顶的 mini 播放器，系统画中画不在当前范围。

如何反馈问题或参与开发？

欢迎到 GitHub Issues 反馈问题，或阅读 开发文档 参与贡献。代码采用 GPL-3.0-or-later；名称与 Logo 遵循独立品牌使用政策。
