## 当前明确边界

- 关闭主窗口必须停止播放器、保存进度并退出整个程序；播放器单独关闭保留主窗口和共享数据库。
- 无多引擎插件、窗口 RPC、JSON 启动兼容协议或语言快照；测试宿主关闭实验原生窗口初始化不影响正式应用。
- 系统 PiP、直接 libmpv 后端替换、SMB 回源与媒体服务器接入不能因为 ADR 已接受而标记为已实现。
- 当前没有 Release 发布版；CI 构建产物与签名、公证、正式发布是不同状态。
